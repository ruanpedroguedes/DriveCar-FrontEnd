# Projeto Gerenciador de Veículos - Frontend

Aplicação cliente desenvolvida em Angular para consumir a API de gerenciamento de veículos.

## 🛠 Tecnologias
- Angular
- TypeScript
- RxJS
- Bootstrap (ou CSS de sua preferência)

## ⚙️ Funcionalidades
- Interface intuitiva para cadastro de carros e marcas.
- Listagem dinâmica dos veículos cadastrados.
- Integração via HttpClient com o Backend Spring Boot.

## 🚀 Como rodar
1. Instale as dependências: `npm install`
2. Inicie a aplicação: `ng serve`
3. Acesse em: `http://localhost:4200`
